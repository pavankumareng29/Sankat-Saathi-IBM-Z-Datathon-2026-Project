# Sankat-Saathi-IBM-Z-Datathon-2026-Project
Sankat Saathi is an AI-powered flood relief platform that prioritizes emergency requests, tracks essential supplies, detects potential duplicates, and recommends resource allocation based on urgency and availability. Powered by IBM Z/LinuxONE.

## Frontend

The responsive React + Vite + Tailwind dashboard lives in [frontend](./frontend). It is currently backed by realistic mock data and is ready to connect to a FastAPI service.

```bash
cd frontend
npm install
npm run dev
```

See [frontend/README.md](./frontend/README.md) for the API handoff guide.
